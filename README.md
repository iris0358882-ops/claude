# Claude — 手帳風聊天前端

純 HTML / CSS / JS，不需要建置。粉色紙張背景、螢光筆底色的對話，以及蓋了郵戳、點開才看得到的「這一輪的思考」。

## 執行

```bash
python3 -m http.server 8000
# 打開 http://localhost:8000
```

（要用本機伺服器開，直接雙擊 `index.html` 的話 ES module 會被瀏覽器擋。）

## 功能

- **示範模式**：沒填 API Key 時用內建的回覆，可以先看效果。
- **接上 Claude**：右上角 ☰ → 填入 API Key。預設模型 `claude-opus-5-5`，
  串流輸出，開啟 adaptive thinking 並顯示思考摘要；被安全分類器擋下時伺服器會自動換模型重試（`fallbacks: "default"`）。
- 對方的回覆會**一行拆成一則**，像一則一則傳訊息；可以連發好幾則，停下來約一秒後對方才回。
- 設定裡可以改對方名字、人設（system prompt）、我的名字、思考強度、背景照片和照片模糊程度。
- 對話與設定都存在瀏覽器的 localStorage。

### 日常小管家

- **今日卡片**（最上面，點一下收合）：日期、天氣、待辦、接下來的提醒。待辦可以直接勾、刪、手動新增。
- **Claude 會用工具**：聊天時說「幫我記…」「提醒我九點…」「明天會下雨嗎」，它會自己新增/完成/刪除待辦、設提醒、查天氣，對話裡會貼一張小標籤顯示它做了什麼。
- **提醒**：時間到會跳系統通知，對話裡夾一張便條；下一次聊天時對方也會知道剛剛提醒過什麼。頁面要開著或留在背景才會跳（iPhone 要先「加入主畫面」才能收通知）。
- **快捷按鈕**：輸入框上面一排，一鍵問今天要做什麼、天氣、記事、設提醒。
- **天氣**用 [Open-Meteo](https://open-meteo.com/)（免費、不用 key），在設定裡改地點或用目前位置。
- 示範模式（沒填 key）也能用「記一下：…」新增待辦，先看效果。

### 記事本（長期記憶）

聊天時對方說了以後還用得到的事（喜好、習慣、重要的人和計畫），Claude 會自己記進記事本，所有角色共用，每次聊天都會帶著。上限 60 條、4000 字，滿了它會自己合併整理。在設定裡可以看、刪、自己加。

聊天紀錄只會送最近 80–120 則給模型（更早的畫面上還看得到），避免越聊越貴；更早的事靠記事本記住。

### 角色

輸入框上面最左邊的紅色按鈕可以換聊天對象，每個角色的對話分開存，待辦和提醒共用。預設有三個：

- **Claude**：照 Claude 原本的樣子說話
- **レイ**：沉穩年上的戀人，會關心你、幫你安排，有點性感
- **ハル**：活潑年下的戀人，很黏人、會撒嬌、會邀功，全程講日文

在設定裡可以改名字和人設，也可以新增或刪除角色。設定裡「我的名字」填了之後，角色會知道怎麼叫你。

### 當成 App 用

這是一個 PWA：用手機瀏覽器打開網站 →「分享」→「加入主畫面」（Android 是選單裡的「安裝應用程式」），就會有自己的圖示、全螢幕打開，離線也開得起來。iPhone 要從主畫面打開，才能在設定裡開啟提醒通知。

- 換圖示：改 `icons/icon.svg`，再輸出成 `icon-512.png`、`icon-192.png`、`apple-touch-icon.png`（180）、`favicon-32.png`。手機會快取圖示，換完要刪掉主畫面上的再加一次。
- `sw.js` 讓 App 離線可用；改了快取清單時把 `CACHE` 的版本號加一。

> API Key 只存在你的瀏覽器裡，並從瀏覽器直接呼叫 API。請只在自己的裝置上使用，不要部署成公開網站給別人用。
