# Grey — 夜間筆記風聊天前端

純 HTML / CSS / JS，不需要建置。黑底米白字配警示黃：頁首是帶黃黑警示帶的筆記卡，你的訊息和對方的問句用方框加錯位陰影強調。

## 執行

```bash
python3 -m http.server 8000
# 打開 http://localhost:8000
```

（要用本機伺服器開，直接雙擊 `index.html` 的話 ES module 會被瀏覽器擋。）

## 功能

- **示範模式**：沒填 API Key 時用內建的回覆，可以先看效果。
- **接上 Claude**：右上角 ⚙ → 填入 API Key。預設模型 `claude-opus-5-5`，
  串流輸出，開啟 adaptive thinking 並顯示思考摘要；被安全分類器擋下時伺服器會自動換模型重試（`fallbacks: "default"`）。
- **帳本**：點頁首右邊的 LOAD（顯示上下文用了多少）會打開帳本，列出本輪的 input / cache read / cache write / output、估算花費、整段對話累計、上下文用量，以及本輪注入給對方的內容。
- **提示快取**：開啟 1 小時快取，聊久了舊對話用快取價計費，便宜很多。
- **時間與天氣注入**：每輪自動告訴對方現在幾點；設定了天氣城市的話也會說那裡的天氣（可在設定關掉）。頁首也會顯示氣溫和天氣，資料來自 Open-Meteo。
- **照片與貼圖**：輸入框下方可以傳照片（Claude 看得懂圖片），或從自己的貼圖庫挑一張。對方也能用貼圖回你：它會在單獨一行寫 `[貼圖:名字]`，畫面上就顯示那張貼圖。
- **思考摘要**是一行「◆ 第一句… 時間 ▼」，點開才展開；你的訊息和對方的問句用方框加紅色錯位陰影強調。
- 對話和貼圖存在瀏覽器的 IndexedDB（放得下照片），設定存在 localStorage。
- 對方的回覆會**一行拆成一則**，像一則一則傳訊息；可以連發好幾則，停下來約一秒後對方才回。
- 設定裡可以改對方名字、頭像、人設（system prompt）、頁首的大標題與副標題、我的名字、思考強度、背景照片、模糊程度、黑白、雨滴動畫。

> API Key 只存在你的瀏覽器裡，並從瀏覽器直接呼叫 API。請只在自己的裝置上使用，不要部署成公開網站給別人用。
